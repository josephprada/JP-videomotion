# Universo de ejemplo

Un personaje completo (`js/persona.js`) sobre el rig del núcleo y su hoja de modelo (`hoja.html`).
No es parte de ningún video: es la base para crear personajes nuevos y la prueba de que el render funciona.

```bash
node nucleo/render.mjs --film universos/_ejemplo --page hoja --stills 0   # → universos/_ejemplo/out/stills/hoja_9x16_0.00s.png
```

## Bloqueo de identidad (así se escribe el de cada personaje)
- Camisa verde azulado con cuello en V; pantalón índigo; tenis blancos con suela coral.
- Pelo oscuro corto con raya; ojos de punto con brillo; sin contorno.
- ~4,6 cabezas de alto.
